## ヒアリング内容（要件）

### クライアント概要

- ゴルフ場を5つ展開（ラウンド回るタイプ）
- 1日約10〜20名、1ヶ月200〜300名（最大500名）
- 大きいゴルフ場3つ（各30名スタッフ）、小さいゴルフ場2つ

### 現状の業務フロー

| 業務 | 現状 |
|------|------|
| 予約 | 楽天GORAからの予約を別管理画面に手動で転記 |
| カート・ロッカー振り分け | 手動で対応 |
| 当日予約確認 | 管理画面を都度確認 |
| スコア入力 | タブレットで入力 |
| 決済 | プレー終了時に実施 |
| キャンセル・変更 | 現状対応不可（雨天時なども） |
| ユーザーとのやり取り | メール・電話 |

### コスト課題

- スタッフ（フロント・事務）の工数がかかりすぎている
- システムコストが把握できていない

### ユーザー側の要望

- SNSログイン
- 事前決済
- 多言語対応
- LINE push通知
- 天気が悪い場合のメール・LINEキャンセル通知

### 管理側の要望

- 顧客分析機能

## フィードバック・気づき

### 裏の目的

- システムを変える背景に隠れた目的がある可能性 → 深掘りが必要

### 資料作成のルール

| ポイント | 内容 |
|----------|------|
| バージョン管理 | v0・v1 とバージョンをつけて共有 |
| 余白 | 揃える。タイトルよりコンテンツは短く |
| フォント・大きさ | 統一する |
| 箇条書き | 点はリスト化する |
| 空白 | 半角スペースで開けない |
| 固有名詞 | 必ず公式名称を使う（楽天GORA、LINE など） |
| スケジュール | 月の境目に縦線・前後の余裕を持たせる |
| タスク漏れ | マニュアル作成・スタッフ育成をスケジュールに追加 |
| 会議体 | POが入っていることを確認する |
| 主語 | 「貴社」「弊社」を使う |
| 図の説明 | 図の目的を必ず一言添える（上司への説明を想定） |

### ドメイン知識について

- **聞いてよい言葉**：聞いたことがある専門用語（ドメイン知識）
- **聞いてはいけない言葉**：ビジネス的な一般用語 → 自分で即調べる
