## KPI体系

### ビジネス指標（North Star）

| 指標 | 定義 | 現在値 | 目標値 | 計測場所 |
|------|------|-------|-------|---------|
| **GMV（月次）** | プラットフォーム上の月次総取引額 | - | - | - |
| **取引件数（月次）** | 月あたりの成約件数 | - | - | - |
| **マッチング率** | 発注依頼 → 成約の割合 | - | - | - |

### プロダクト指標

| 指標 | 定義 | 現在値 | 目標値 |
|------|------|-------|-------|
| 見積回答率 | 打診に対してパートナーが見積を返した割合 | - | - |
| 平均見積回答時間 | 発注依頼からパートナーの見積回答までの時間 | - | - |
| 発注完了率 | 見積取得後に実際に発注した割合 | - | - |
| リピート率 | 2回以上発注したバイヤーの割合 | - | - |

### ユーザー指標

| 指標 | 定義 | バイヤー | パートナー |
|------|------|---------|---------|
| MAU | 月次アクティブユーザー | - | - |
| NPS | 推奨度スコア | - | - |
| チャーン率 | 月次の離脱率 | - | - |
| 新規登録数 | 月次の新規登録数 | - | - |

## 指標の読み方・注意点

**GMVとテイクレートの関係：**

```
収益 = GMV × テイクレート（手数料率）
```

GMVが上がっても、マッチング率・発注完了率が低いと
実際の収益に結びつかないため、ファネル全体で見ることが重要。

**ファネル構造：**

```
サービス訪問
    ↓ 登録率
バイヤー登録
    ↓ 発注依頼率
発注依頼
    ↓ マッチング率
パートナーとのマッチング
    ↓ 見積回答率
見積取得
    ↓ 発注完了率
発注確定（GMVカウント）
    ↓ リピート率
再発注
```
