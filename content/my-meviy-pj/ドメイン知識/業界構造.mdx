## 製造業の全体像

製造業とは、原材料・素材を加工して製品を作る産業。
meviy Marketplaceが関わるのは、主に「加工部品の調達」フェーズ。

## バリューチェーン

```
設計・開発 → 部品調達 → 製造・加工 → 組立 → 検査 → 納品・販売
              ↑
         ここに meviy が入る
```

| フェーズ | 内容 | meviyとの関係 |
|---------|------|-------------|
| 設計・開発 | 3D CADで部品を設計 | 図面・3Dデータをアップロードして発注 |
| **部品調達** | 加工業者を探し、発注・納品管理 | **meviy Marketplace のコアドメイン** |
| 製造・加工 | 金属・樹脂を削る・曲げる・溶接する | パートナー（加工業者）が担当 |
| 組立 | 部品を組み合わせて装置・製品に | 発注企業側が実施 |
| 検査 | 寸法・品質の確認 | ミスミ基準での品質保証 |

## 製造業調達の商習慣

### 従来の調達フロー（meviy導入前）

```
1. 図面を準備
2. 複数業者に見積依頼（電話・FAX・メール）
3. 見積書を比較（数日〜数週間かかる）
4. 発注・納期調整
5. 納品・検収
```

**課題：**
- 見積に時間がかかる（平均数日〜1週間以上）
- 業者探しがつながりに依存（属人的）
- 品質・納期の見通しが不透明

### meviy導入後のフロー

```
1. 図面・3Dデータをアップロード
2. 条件（材質・加工・数量・納期）を入力
3. マッチするパートナーに一括打診
4. 最短当日〜翌日に見積回答
5. 発注・最短1日目出荷
```

## 製造加工の種類（基礎知識）

| 加工種別 | 読み方 | 内容 | 特徴 | 使用製品例 |
|---------|--------|------|------|----------|
| 切削加工 | せっさくかこう | 素材を削って形を作る | 高精度・金属向き | 半導体装置のフレーム・治具、医療機器本体ケース、カメラ鏡筒 |
| 旋盤加工 | せんばんかこう | 素材を回転させながら削る | シャフト・丸棒形状 | モーターのシャフト、油圧シリンダーのロッド、産業ロボットの関節部品 |
| 板金加工 | ばんきんかこう | 薄い金属板を曲げる・打ち抜く | 筐体・カバー向き | 装置の外装カバー・ドア、電気制御盤の筐体、サーバーラックパネル |
| 溶接 | ようせつ | 金属を熱で接合 | 強度が必要な構造体 | 搬送ラインのフレーム、架台の補強、配管接合 |
| 製缶加工 | せいかんかこう | 板金より厚い鉄板を溶接して大型構造物を作る。重くて強度が必要なものに使われる | フレーム・タンク等 | 半導体装置の架台・ベース、工場の搬送ライン・コンベア、化学プラントのタンク、クレーンのアーム |
| 3Dプリント | スリーディープリント | 樹脂を積層して形を作る | 試作・短納期向き | 製品の試作モデル、製造ラインの治工具、医療機器プロトタイプ |
| 射出成形 | しゃしゅつせいけい | 溶かした樹脂を型に流す | 量産向き・金型が必要 | 家電のボタン・ケース、医療機器の使い捨て部品、自動車内装パーツ |

### 業種別ビジネスモデルの特徴と調達ニーズ

| 業種 | ビジネスモデルの特徴 | 調達ニーズの特徴 |
|------|--------------------|--------------------|
| 半導体装置 | 受注生産・高単価。設計変更が多い | 試作の速度が勝負。短納期・小ロットのカスタム部品 |
| 医療機器 | 規制産業。品質・トレーサビリティが必須 | 品質保証済みの加工業者との取引が前提 |
| 産業ロボット | 量産＋カスタム対応の両立 | 標準品だけでは対応できないカスタム架台・治工具 |
| 計測・検査機器 | 高精度が要求。ニッチ市場でシェア型 | 公差の厳しい高精度切削部品 |

### PMが押さえるべきポイント

- **大手メーカーの購買部門がメインユーザー**：個人の意思決定ではなく、社内稟議・サプライヤー登録フローがある
- **設計エンジニアが発見・推薦し、購買部門が承認・発注**というツーステップ構造が多い
- **試作フェーズでの利用が入口**になりやすく、そこからリピートにつなげる導線設計が重要
- **品質クレームは顧客の製品品質に直結**するため、パートナーの品質管理はLTV・チャーンに直接影響する
