## 製造・加工用語

| 用語 | 読み | 意味 |
|------|------|------|
| 切削加工 | せっさくかこう | 刃物で素材を削り、形状を作る加工法 |
| 旋盤加工 | せんばんかこう | 素材を回転させながら刃物で削る加工。シャフト・軸類に多用 |
| 板金加工 | ばんきんかこう | 薄い金属板をプレス・曲げ・打ち抜きで形を作る加工 |
| 製缶加工 | せいかんかこう | 厚板の溶接・切断・機械加工。フレームやタンクの製作 |
| 5軸加工 | ごじくかこう | X/Y/Z + 回転2軸で複雑な形状を一度の段取りで加工。高精度 |
| 複合旋盤 | ふくごうせんばん | 旋盤と切削の機能を持つ複合機。複雑な軸形状に対応 |
| 射出成形 | しゃしゅつせいけい | 溶融樹脂を金型に射出して固める成形法。量産に適する |
| 注型 | ちゅうけい | 液状樹脂を型に流し込む成形法。小ロット・試作向け |
| 治工具 | じこうぐ | 製造現場で使う補助器具（ジグ・フィクスチャ等） |
| 公差 | こうさ | 寸法の許容誤差範囲。例：10mm ±0.05mm |
| 素材 | そざい | 加工前の材料。アルミ・ステンレス・樹脂など |
| 材質 | ざいしつ | 使用する材料の種類。A5052（アルミ）・SUS304（ステンレス）など |

## 設計データのファイル形式（詳細解説）

### 2D図面のファイル形式

2D図面とは「紙の設計図をデジタル化したもの」。正面・側面・上面から見た形状を平面で表現する。

```
【2D図面のイメージ】

  正面図        側面図        上面図
 ┌──────┐    ┌────┐    ┌──────┐
 │      │    │    │    │  ○   │
 │      │    │    │    │      │
 └──────┘    └────┘    └──────┘

→ 3方向から見た形を組み合わせて立体を理解する
```

| 形式 | 拡張子 | 特徴 | 主な用途 |
|------|-------|------|---------|
| **DXF** | .dxf | AutoCADの標準形式。テキストベースで軽い。ほぼ全CADで開ける | 2D図面の共有・入稿に最も広く使われる |
| **DWG** | .dwg | AutoCADのネイティブ形式。DXFより情報量が多いが互換性はやや低い | AutoCAD同士のやり取りに使う |
| **PDF** | .pdf | 閲覧・印刷用。編集不可。寸法情報が失われる場合がある | 確認・承認フローに使う（加工データとしては不向き） |

> **PMが知っておくべきこと**：meviyでは2D図面（DXF等）＋3Dデータ（STEP等）を組み合わせて入稿することが多い。2Dだけでは公差・注記が読み取れず、3Dだけでは細部の仕様が不明なため。

---

### 3Dデータのファイル形式

3Dデータとは「立体形状をコンピュータ上で表現したもの」。そのままの形で部品の形状・寸法を確認できる。

```
【3Dデータのイメージ】

        /|
       / |
      /  |     ← コンピュータ上で回転・拡大・断面確認ができる
     /   |
    /____|

→ 1つのデータで全方向から形状を把握できる
```

| 形式 | 拡張子 | 特徴 | 主な用途 |
|------|-------|------|---------|
| **STEP** | .step / .stp | CADソフト間の標準交換形式。形状・色・アセンブリ構造を保持 | **meviyへの入稿で最もよく使われる** |
| **IGES** | .iges / .igs | 古い標準形式。現在はSTEPに置き換えられつつある | レガシー対応・古いCADとのやり取り |
| **STL** | .stl | 表面を三角形の集合で表現。ファイルが大きくなりがち | **3Dプリント専用**（切削・板金加工には不向き） |
| **PARASOLID** | .x_t / .x_b | SolidWorks・NX間で使われる高精度形式 | 大手メーカー間の高精度データ共有 |
| **独自形式** | .sldprt など | 各CADソフト固有の形式。他社CADでは開けない | 社内保管用 |

---

### 2Dと3Dの使い分けイメージ

```
【バイヤーがmeviyに入稿するとき】

3Dデータ（STEP）          2D図面（DXF/PDF）
├ 部品の全体形状          ├ 公差（±0.05mmなど）
├ 穴の位置・深さ          ├ 表面処理の指示
├ 大まかな寸法            ├ 材質・仕上げ指定
└ パートナーが加工機に     └ 検査基準・注記
  プログラムを作る際に使う    （3Dデータでは表現できない情報）

→ 両方セットで初めて「完全な発注情報」になる
```

### よくある混乱ポイント

| 質問 | 答え |
|------|------|
| STEPとSTLは何が違う？ | STEPは「正確な数学的形状」、STLは「三角形の近似」。切削加工にはSTEP必須 |
| DXFで発注できる？ | 2Dだけでは情報不足なことが多い。3DデータのSTEPと合わせて入稿が基本 |
| PDFの図面では加工できない？ | PDFは「見るため」の形式。加工業者はCADデータ（DXF/STEP）が必要 |
| CADソフトが違うとデータを開けない？ | 独自形式（.sldprt等）は開けないが、STEPに変換すれば異なるCAD間でも共有できる |

## プロダクト管理用語（PM向け）

| 用語 | 意味 |
|------|------|
| ロードマップ | 製品の将来の機能・方向性を時系列で示した計画 |
| スプリント | アジャイル開発の1単位。通常1〜2週間 |
| バックログ | 未着手の機能要件・改善タスクの一覧 |
| ユーザーストーリー | ユーザー視点で書いた機能要件。「〜として、〜したい、なぜなら〜」 |
| KPI | Key Performance Indicator。成功を測る主要指標 |
| OKR | Objectives and Key Results。目標管理フレームワーク |
| PMF | Product-Market Fit。製品が市場のニーズに合っている状態 |
| DAU / MAU | 日次/月次アクティブユーザー数 |
| A/Bテスト | 2つのバージョンを比較して効果を測定する手法 |
| ステークホルダー | プロジェクトの利害関係者（経営・営業・開発・ユーザー等） |
