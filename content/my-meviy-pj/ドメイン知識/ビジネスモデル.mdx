## meviy Marketplaceのビジネスモデル

### 基本構造：マーケットプレイス型（推定）

```
発注企業（バイヤー）
    ↓ 部品発注・代金支払い
meviy Marketplace（ミスミ）
    ↓ 手数料（テイクレート）を差し引いて
加工業者（パートナー）
    ↓ 部品を製造・納品
発注企業（バイヤー）
```

**収益源（推定）：**

| 収益源 | 内容 |
|-------|------|
| 取引手数料 | 成約時にGMVの一定割合をミスミが受け取る |
| 掲載料・月額費用 | パートナーが登録・掲載するための費用（推定） |
| オプションサービス | 優先表示・品質保証オプション等 |

> ※ 公式発表ベースではないため、実態は参画後に確認すること

### ミスミ本体との関係

| 項目 | 内容 |
|------|------|
| ブランド関係 | meviyはミスミの標準品ECに隣接するブランド |
| ミスミ既存事業 | 規格品（標準品）のECが主力。カタログ発注モデル |
| meviy Marketplaceの位置づけ | 標準品では対応できない「カスタム加工品」の調達をカバー |
| 相互補完関係 | 標準品EC × カスタム加工マーケットプレイスで調達をワンストップ化 |

## 競合比較

### 直接競合（製造業マーケットプレイス）

| 企業/サービス | 特徴 | meviyとの違い |
|-------------|------|-------------|
| キーエンスのサービス系 | 計測・FA機器が主力、加工は周辺 | meviyは加工部品特化 |
| PRAS（プラス） | 板金加工特化のマーケットプレイス | meviyはカテゴリが広い |
| 個別加工業者のEC | 各社がバラバラに展開 | meviyは審査済み多数のパートナーを集約 |

### 間接競合（従来の調達手段）

| 調達手段 | 特徴 | meviyの優位性 |
|---------|------|-------------|
| 電話・FAXでの直接発注 | 慣れている・関係構築済み | スピード・比較・デジタル記録 |
| 既存サプライヤー（固定） | 信頼関係がある | 新規業者へのアクセス・競争価格 |
| 商社経由 | 手間がかからない | コスト・スピード・透明性 |

## 顧客の購買決定要因（KBF）

製造業における加工部品調達のKBF（Key Buying Factors）：

| 優先度 | 要因 | meviyの対応 |
|-------|------|-----------|
| 1 | **品質・精度** | ミスミ基準での審査・品質保証 |
| 2 | **納期・リードタイム** | 最短1日出荷・納期コミット |
| 3 | **価格** | 複数パートナー比較で競争促進 |
| 4 | **対応力（材質・加工種別）** | 8カテゴリ・多数パートナーで幅広く対応 |
| 5 | **手続きの簡易さ** | デジタル一本化・図面アップロードで完結 |

## 成長ドライバー（仮説）

```
パートナー数増加
    → 対応品種・納期の選択肢が増える
    → バイヤーの満足度向上
    → GMV増加・新規バイヤー獲得
    → ネットワーク効果でさらにパートナーが集まる
```

**ボトルネック（推定）：**

- パートナー審査の厳しさ → 品質維持 vs 供給拡大のトレードオフ
- 購買担当者のデジタルリテラシー → 従来手法からの移行障壁
- カテゴリ拡張の難易度 → 専門性の高い加工領域ほど審査・品質管理が複雑
