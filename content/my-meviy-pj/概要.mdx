## サービス概要

| 項目 | 内容 |
|------|------|
| サービス名 | meviy Marketplace（メビーマーケットプレイス） |
| 運営会社 | 株式会社ミスミグループ本社 |
| ポジション | 日本最大級の製造業マーケットプレイス |
| 一言説明 | ミスミ基準で審査済みのパートナーから加工部品を最短1日で手配できるB2Bプラットフォーム |
| サービスURL | https://jp.marketplace.meviy.misumi-ec.com/ |

## meviy ファミリー（サービスラインナップ）

meviy Marketplace は「meviy 全方位構想」の一部として展開されている。コアサービスの meviy を中心に、エンジニアリングチェーンの非効率を解消する関連サービスが順次リリースされている。

| サービス | 開始時期 | 概要 |
|---------|---------|------|
| **meviy**（コア） | 2019年〜 | 3D CADデータをアップロードするだけで即時見積り・最短1日出荷を実現する機械部品調達プラットフォーム |
| **meviy 2D** | 2023年6月〜 | PDF・DXF・DWG の2D図面データをアップロード → AIが解析して自動見積り・最短1日出荷 |
| **meviy Finder** | 2024年8月〜（**無償**） | 図面をアップロードすると類似図面検索・キーワード検索が可能になるAI。外形寸法も含めた類似判定が特徴 |
| **meviy Marketplace** | 2024年9月〜 | 製造業マーケットプレイス。図面をアップロードしてパートナー企業と自動マッチング。見積回答は最短15分 |

### サービス間の連携・棲み分け

```
カタログ（規格品）
    ↓ 対応できない場合
meviy（3D図面品・自動見積り）
    ↓ meviyで製造不可と判定された場合、自動移行
meviy Marketplace（より複雑・特殊な加工品）
```

> meviy と meviy Marketplace はシステム連携しており、meviy で製造不可と判定された製品は自動的に Marketplace へ移行して見積り依頼ができる。

## 解決している課題

**ユーザー（購買・調達担当）が抱える課題：**

- 加工部品の調達先を自力で探すのが手間・時間がかかる
- 品質・リードタイムの見通しが不透明
- サプライヤーとのやり取り（見積・交渉）に工数がかかる

**meviy Marketplace が提供する価値：**

- ミスミ基準で審査済みパートナーのみ掲載 → **品質保証**
- 条件にマッチするパートナーとダイレクトにやり取り → **スピード・透明性**
- 最短1日目出荷で手配完結 → **リードタイム短縮**
